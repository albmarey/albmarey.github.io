Unreal Engine 5 RPG
This unannounced project is an RPG built using Unreal Engine 5.8, developed entirely by me using C++ and Blueprints over the course of about a year and a half. I started with version 5.5 and gradually updated it until I reached the latest version of Unreal Engine.
I am currently continuing to develop it, with its main features centring on the use of GAS and, as the core mechanic, the Dungeons & Dragons skill checks seen in Baldur’s Gate 3, turning this into a skill-based game.
The game loop is inspired by the RPG *Blades in the Dark*. The player explores the city with a criminal gang to gather information needed to complete an operation. Once gathered, they carry out the operation as a skill check. Finally, they use the results to improve their crew.
If you want to see code, ask me.

Project details
  • Designed a skill-based testing system inspired by Baldur’s Gate 3 and Citizen Sleeper.
  • Gameplay Ability System
    • Gameplay ability execution on player targets and party characters.
    • Gameplay effects application with different times.
    • Gameplay effect calcultation for resistance and damage types.
    • Gameplay events for triggered abilities.
    • Data assets and data tables for static data.
    • Attribute sets for different types of characters
  • Designed and Implemented the User Interface (UI) and UX:
    • Implemented HUD.
    • Implemented card drag and drop system.
    • Implemented widget animations when gameplay abilities are executed.
    • Tooltip system for player information.
  • Implementation of a dialogue system.
  • Game calendar for events.
  • Reputation system with factions based on Fallout: New Vegas.
  • Day night cycle.
  • Enviroment interactables: chests, containers, levers and buttons.
  • Quest System.
  • Inventory System
