Demons & Knight
I chose to work on this project whilst I was at 42 Madrid to learn about computer graphics. It’s a game in the style of classic roguelikes, where the aim is to find the key and escape the level.
Project Details
The aim of the Demons & Knight (So_Long) project is to develop a game that incorporates map rendering, character movement, collision detection, item collection, and victory and defeat conditions.
Allows you to load and render game maps stored in a file with a .ber extension. The map consists of different tiles representing walls, paths, collectible items, the player's starting position, and the exit. The MinilibX library provides functions to render graphical elements on the screen, enabling you to display the map with the appropriate textures and colors.
The player can move in four directions: up, down, left, and right, within the bounds of the map. By handling keyboard inputs, you can update the player's position on the screen accordingly.
The player cannot pass through walls or go beyond the boundaries of the map, thanks to a collision detection system. The game checks whether the movement performed will result in a collision with a wall, an enemy, the edge of the map or an item.
The victory condition is met when the player successfully reaches the finish tile. On the other hand, the defeat condition can be triggered by colliding with enemies.
