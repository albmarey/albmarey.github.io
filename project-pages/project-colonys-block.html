Colony's Block
In the Multiplatform Application Development degree program, we were able to choose our final-year project. So I chose to create a prototype for an RTS game in Unity.
Project Details
  • World Generation
    • Map generation using Minecraft-style cubes, chunks and Perlin noise.
    • Dynamic Navmesh adjusted to the map generation for minion movement.
    • Randomly spawn scenery elements such as trees, rocks and resources.
    • Biome information for texture changes and new maps.
  • Building System
    • A farm building for producing food.
    • A storage building to increase resource capacity.
    • A resource system based on food and gold, where each unit and building consumes these resources over time.
  • Unit Controllers
    • Unit attributes such as lifespan, food consumption over time and speed.
    • Movement of units across the scene, without animations for jumping between different levels.
  • User Interface
    • Design and implementation of the Title Menu.
    • Design and implementation of the Pause Menu.
    • Design and implementation of the HUD.
  • Game events stored in a local database built using SQL and C#.
